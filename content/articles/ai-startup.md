# How I Built My AI Startup

In this article, I share my journey of building and launching an AI-powered SaaS product.

## The Problem Statement

Many businesses struggle with manual data entry. We designed a solution using Large Language Models to automate structured extraction from raw text.

## Tech Stack Decisions

We chose:
- **Frontend:** Next.js & Tailwind CSS
- **Backend:** Node.js, Express & PostgreSQL
- **AI Orchestration:** Google Antigravity SDK & Gemini API

## Key Takeaways

1. **Focus on Latency:** Streaming responses is key to user experience.
2. **Robust Prompts:** Structured JSON schema outputs save engineering hours.
3. **Analytics matter:** Track LLM usage and token costs early on.
